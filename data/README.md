# Datos

Esta carpeta no se versiona (salvo este README): contiene datos personales de entrenamiento.

- `raw/`: exportación original de Strava/Garmin (`.fit`, `.fit.gz`, `.gpx`, `.gpx.gz`, `activities.csv`).
- `processed/`: datos limpios generados por el código.

Los datos de ejemplo para tests van en `tests/fixtures/`, anonimizados o sintéticos.
